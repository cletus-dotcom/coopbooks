Design Notes
Copy-paste workflow

Coops export from Excel/Legacy systems, paste into templates, and upload without manual SQL.

Foreign keys as codes

Use member_no, account_code, and entry_no instead of database IDs.

Per-coop isolation

Each cooperative code routes imports to that coop’s dedicated PostgreSQL database.
